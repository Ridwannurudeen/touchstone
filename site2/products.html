Five parts, one record

Everything Touchstone ships serves one artifact: a signed report over an issuer's own disclosures. The five parts below compile it, evaluate it, publish it, let you check it, and — when the consumer contract is deployed — let a protocol act on it.

Dossier

The published output: a signed epoch report per covered asset. It carries every control result, every digest, the state transition, and the five limitations — all under one Ed25519 signature.

Read about the dossier →

Control Language

The unit of verification. A control names its subject, cites the byte-exact issuer span it was compiled from, and states a predicate a deterministic engine can evaluate without judgment.

Read about controls →

Verifier

Offline verification of a downloaded bundle: the signature, the approval-ledger digest, the compilation artifacts, all eight content hashes, and both roots — recomputed on your machine, without trusting this site.

Read about verification →

AssetGatetestnet only Not deployed

The consumer contract, written to gate on a report's status, freshness, publisher lineage and pinned control-set root. It is not deployed; nothing reads the registry in production today.

Read about AssetGate →

Registry

The on-chain record on X Layer testnet, chain id 1952. Reports are published in sequence, permanently; a later report can correct an earlier one by naming it, never by overwriting it.

Read about the registry →

How they fit

From issuer bytes to an on-chain state

  1. 1

    The control language fixes the claim

    A control is compiled from the issuer's published documents and cites the exact bytes it was drawn from. A human approves or declines each candidate; declines are recorded with reasons.

  2. 2

    The engine evaluates, or abstains

    Each epoch, fresh evidence is retrieved and every approved control is evaluated. A control the evidence cannot answer is reported unevaluable, not skipped.

  3. 3

    The dossier binds and signs the result

    Results are bound by content hash, control set root and evidence root, then signed with Ed25519. The five limitations travel inside the signed bytes.

  4. 4

    The registry makes it permanent

    The report is published to the registry contract on X Layer testnet, at a sequence number, checkable by anyone.

  5. 5

    The verifier and AssetGate read it back

    Anyone can verify the bundle offline today. AssetGate consumes the registry state on-chain and is live on X Layer testnet, where it currently refuses USTB. It is not deployed on mainnet.

Written for

Where this record is meant to be used

Written for, not used by — no one consumes Touchstone in production today, and this site does not pretend otherwise.

Collateral gating

A lending protocol that accepts a tokenized fund as collateral can require a current report in a satisfied state before it values the asset — and can refuse or haircut it the moment the state is UNVERIFIABLE or the report has expired.

Disclosure monitoring

An operations or risk team can watch the registry instead of the issuer's website: every control result is sequenced, signed and permanent, and an abstention is recorded with the same weight as a pass.
