What this page is

This is the one scripted page on the site. Its code is served from this host (app.js, ethers 6.17.0, MIT), it talks only to X Layer RPC endpoints, and it holds no keys and no state. The static proof pages — dossier, verify, judge — work with JavaScript disabled entirely.
