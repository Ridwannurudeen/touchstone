Every asset, with its honest status

The direction is expansion beyond one asset, and an auditor has just ruled the order. This page states that ruling and nothing more optimistic. Statuses are facts, not aspirations — an asset not yet live is shown with the exact work that opens it.

Asset coverage, ruled by audit
Asset Status What stands
USTB Invesco/Superstate Short Duration U.S. Government Securities Fund LIVE One published report, sequence 1, X Layer testnet. Three issuer JSON sources: superstate-ustb-nav-daily, superstate-ustb-yield, superstate-ustb-holdings.
OUSG Ondo Short-Term U.S. Government Treasuries NEXT Ruled the fastest credible second asset: a bounded ~732 KB page with real business-day movement and no archive dependency. Open work is concrete — no committed fixture, no normalizer, extraction anchors unselected, oracle cross-check incomplete. Its evidence is issuer-published HTML, not a documented JSON API.
FOBXX Franklin OnChain U.S. Government Money Fund OPEN · MONTHLY The strongest evidence model found so far — an issuer source and an SEC N-MFP3 regulator source that can be reconciled against each other. The regulator path is live and bounded, re-verified 2026-08-18: data.sec.gov returns HTTP 200 in 29,354 bytes with 68 N-MFP3 filings, the latest filed 2026-08-06 for period 2026-07-31. That is filed-with-a-regulator evidence rather than an issuer API, and it is the strongest provenance of any source here. It ships monthly, which is the cadence a money-market fund files at. The daily issuer endpoint returned Cloudflare 403 and the Benji API requires client credentials. Monthly regulator-backed only until production-host access is proven.
USDY Ondo U.S. Dollar Yield OPEN Reopened 2026-08-18 by measurement. The suspension treated USDY as one source; it is two. Only the attestation archive is the 260 MB one. The daily portfolio page returns HTTP 200 in 1,544,898 bytes and carries asOfDate, collateralizationRatio, outstandingValue, total and per-holding rows inline — bounded, and richer than any source now live. It is the first source here that can carry a coverage predicate (total >= outstandingValue) rather than a presence check. Daily attestations stay out of reach: HTTP range requests on the archive return 200 with all 260,640,295 bytes, and the folder page carries no server-rendered listing.

Assets under evaluation but not selected — BUIDL, ACRED, Hashnote, Backed, Centrifuge — because no stable public retrieval surface has been verified for them. A brand name is not an ingestion contract.

The operator ceiling

The registry is structurally multi-asset and could carry ten. The current single-operator design supports two or three daily assets. Publishing that limit is the kind of thing this project says out loud.
